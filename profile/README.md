# 삼구아이앤씨 DX전략팀

삼구아이앤씨 DX전략팀의 사내 시스템 소스코드와 산출물을 관리하는 조직입니다.

## About
- 삼구아이앤씨는 건물관리(FM), 물류·생산도급 분야의 인력 아웃소싱 전문 기업입니다.
- DX전략팀은 사내 업무 시스템의 개발·운영과 디지털 전환을 담당합니다.
- 이 조직에서는 사내 시스템의 코드와 개발 이력을 한곳에서 관리합니다.

## How We Work
- 모든 변경은 이슈 등록 → 브랜치 작업 → Pull Request → 코드 리뷰 순서로 진행합니다.
- 작업 규칙은 [CONTRIBUTING](../CONTRIBUTING.md)을 따릅니다.
