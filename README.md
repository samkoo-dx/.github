# .github

samkoo-dx 조직 공통 기본 파일 레포 · DX전략팀 관리

## 1. 역할

- 조직 내 모든 레포에 적용되는 기본 양식 · 작업 규칙 보관
- 레포에 같은 종류 파일이 없으면 이 레포 파일이 자동 적용
- 레포에 자체 파일이 있으면 레포 파일 우선 (예: GitHub Flow 전환 레포의 PR 양식)

## 2. 파일 구성

| 파일 | 용도 | 적용 위치 |
|---|---|---|
| `CONTRIBUTING.md` | 공통 작업 규칙 (GitHub Flow) | 각 레포 이슈 · PR 화면의 작업 규칙 링크 |
| `CONTRIBUTING-gitflow.md` | 기존 규칙 (전환 전 레포 · 이력 보관) | 전환 완료 후 삭제 예정 |
| `.github/ISSUE_TEMPLATE/` | 이슈 양식 6종 (기능 · 오류 · 운영 · 문서 · 리팩토링 · 테스트) | 새 이슈 작성 화면 |
| `.github/pull_request_template.md` | 기본 PR 양식 (전환 전 레포용) | 새 PR 작성 화면 |
| `profile/README.md` | 조직 첫 화면 소개 | 조직 Overview |

## 3. 운영 원칙

- 공개 레포 → 사내 인프라 · 시스템명 · 계정 · 주소 등 내부 정보 기재 금지
- 상세 정책 · 사용 방법 · 룰셋 설명은 비공개 레포 문서로 관리 (repo-template `docs/`)
- 양식 변경 시 이슈 접수 · PR 검사 자동화와 항목명 일치 여부 확인 (항목명이 다르면 검사 실패)
- 변경 · 문의: DX전략팀
